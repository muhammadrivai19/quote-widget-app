# QuoteWidget — Store Assets (draf v1)

## Short description (<=80 char)
Quote bergantian di home screen, offline, tanpa akun.

## Full description (ID)
QuoteWidget menampilkan quotes favoritmu di home screen Android.

- Tulis & kelola quotes sendiri (maks 200 karakter per quote)
- Widget persegi panjang, bisa di-resize, tombol next/previous
- Ganti otomatis tiap 15 menit – 24 jam (WorkManager, hemat baterai)
- 4 tema: Terang, Gelap, Biru, Senja (semua gratis di v1)
- Quote Viewer: geser kiri/kanan + mode bersih untuk screenshot
- 100% offline, tanpa akun, data hanya di perangkat
- Tetap jalan setelah restart HP

Catatan: update otomatis bisa meleset beberapa menit karena hemat baterai Android. Ini normal.

## Privacy policy (draf, host di web sebelum rilis)
QuoteWidget tidak mengumpulkan, menyimpan, atau membagikan data pribadi apa pun. Semua quotes dan pengaturan hanya tersimpan di perangkat pengguna. Tidak ada akun, tidak ada analitik, tidak ada iklan, tidak perlu internet (kecuali download dari Play Store).
